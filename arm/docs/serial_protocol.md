# R9D机械臂当前接线与串口命令

当前STM32F407VET6、HSE25MHz/168MHz。普通ASCII行结尾CR/LF；USART1 PA9 TX/PA10 RX，115200 8N1，USB串口交叉连接。UART4 PC10 TX→Emm RX、PC11 RX←Emm TX，地址5。PC6夹爪1、PC7云台2、PC8料盘3；独立执行器供电与主板共地。此目录与底盘独立，不能把PA0/PA1的底盘电机接线套来。

## 只读及单轴

| 命令 | 含义 |
|---|---|
| `?` / `status` / `points` | 帮助、使能/参考/任务/停机快照、当前高度及保存状态 |
| `probe` | 驱动器配置/目标/误差/状态/位置查询，不运动；等结束 |
| `r` / `flags` / `tpos` / `perr` / `current` / `voltage` | 位置、状态、目标、误差、电流、电压 |
| `seed 1 1560` | 在已知夹紧姿态首次输出1560；即时启PWM，不是缓动 |
| `seed 2 1000` / `seed 3 1450` | 只在当前确实对应车内/中盘姿态时初始化 |
| `rate 1 250` | 设置该通道缓动速率μs/s；另可通道2/3 |
| `servo 1 1850` / `servo 1 1560` | 夹爪张开/夹紧，等待SERVO_DONE |
| `servo 2 2130` / `servo 2 1000` | 车外/车内；必须有完整旋转空间 |
| `servo 3 550` / `1450` / `2350` | 料盘三工位；后两条完整写法也需servo 3前缀 |
| `j 1 -20` | 舵机1相对减20μs；j 2/3同理 |
| `off 1` | 关闭指定舵机PWM，失去保持力，先确认支撑 |
| `jawlimits 1380 2260` | 夹爪软件允许范围，不是云台turnlimits；未实测端点不盲到 |
| `turnlimits 1000 2130` | 云台工作范围，不能用来修改夹爪 |
| `speed 20` / `accel 20` | 升降RPM/驱动器加速度参数，不运动 |
| `arrival app 20` / `arrival strict` | 应用容差或驱动器严格判稳；不是免检继续 |
| `limits MIN MAX` | 升降LOCAL软范围，需参考有效且包含实际位置/目标 |
| `jog 50` / `jog -50` | 升降相对±50输入脉冲，单次范围−100..100；正向通常向下 |
| `lift LOCAL` | 到该LOCAL绝对目标；有零点和范围条件 |
| `stop` / `!` | 停任务/升降，舵机保持；不会自动松爪 |

任务实际参数：夹紧1560、松1850；云台内1000/外2130；盘550/1450/2350。seed只是首次对齐当前姿态，后续用servo/j；反馈中的SERVO_DONE指软件PWM到目标，没有角度/接触传感器。

## 物理零点与手动量高度

Emm绝对位置是驱动器当前计数坐标，不是跨断电绝对物理高度。最新高度留在原板Flash，历史calibration_20261027.json不能直接用于新板。

1. 空爪、支撑升降，probe完成后发`measure on`，等MEASURE_READY。未完成禁能前不手掰。
2. 移到可重复安全零点，停稳，`datum new fresh`会清空旧高度以重标；只需换坐标且旧参考仍有效用`datum new`，不要混用。
3. 支撑不撤，`measure hold`，等成功再放手；失败保留支撑并读状态，不能硬跑任务。
4. 再measure on，逐个实际摆位并记录下表；最后回安全位、measure hold成功、`save`、`points`。

| 实测高度 | 命令 |
|---|---|
| 车外抓物料 | `point grabpick` |
| 朝内把物块放稳料盘 | `point grabdrop` |
| 从料盘可靠夹起物料 | `point tray` |
| 粗加工松爪放稳 | `point rough` |
| 精加工叠放另一物块上 | `point stack` |
| 带块可安全转整段的避让点 | `point clearance` |

建议`swing off`保持转向/下降不重叠。`save`写sector7并读回校验。掉电后回到之前物理零点才能`datum at zero`；也可在确实对准已保存高度时`datum at grabdrop`等恢复。不知道实际位置时不能凭数字恢复。
不需要每次重新量所有高度，但每次上电的物理参考条件必须成立；没有经过验证的自动回零流程。测量保持阶段若下滑或发生使能计数重置，程序可能拒绝；看MEASURE_ERROR而非反复清零。

## 完整取放

`grab`或`grab 2`默认入中间盘；`grab 1/3`选择相应工位。物块应在车外2130姿态夹点下，底盘先对齐；升降有正确参考及已保存高度，首次冷启动须停在标定物理零点。自动准备不等于自动识别任意起始姿态。
`rough 1/2/3`从对应盘取料到粗加工；`stack 1/2/3`从盘取料到精加工已有块上。云台都朝外2130，底盘负责工位位置及朝向。tray高度与grabdrop不能假定相等。
一次只发一个任务，等待完成后再下一次。缺高度、过期反馈、故障、测量未退出或软范围会拒绝，读status/points；不要靠重启掩盖。超时保爪，避免自动掉料。旧`grab setup`是历史标定路径，不作为本版一键任务的准备建议。
迁入arm仅离线验证，真实取放证据为用户10月29日反馈。本次没有实物重跑。
