# F407 主控与新机械臂 v2.7.43 交接

2026-11-19 · 主控候选 `v2.7.43-arm2-preview-20261118`，雷达板 `LD19_BENCH_F407VE_0.3.5_FRONT150`，两板都用 STM32F407VET6、25 MHz HSE 和 168 MHz SYSCLK。

整车接线、轮序、LD19 四根线、共用电机总线及新增轴地址见[整车接线表](WIRING_20261119.md)。旧版命令说明与通信帧速查见[历史接线与命令](WIRING_AND_COMMANDS.md)和[双板协议](LIDAR_LINK.md)。

## 工程和构建

| 目录 | 内容 |
| --- | --- |
| 根目录 `src/`、`include/` | F407 主控，非阻塞串口调度、底盘控制、里程计、雷达观测、路径规划、视觉和任务状态机 |
| `src/nav/generated/`、`src/nav/qp/` | 已供 MCU 运行的生成 C 和数值运算依赖 |
| `arm/` | 集成主控复用的原机械臂状态机和标定存储，以及参考独立工程 |
| `lidar/firmware/` | LD19 处理板，CMake + Ninja，STM32 HAL/CMSIS，环形 DMA 采集和整车链路 |

从仓库根目录执行 `python scripts/build_nav.py` 和 `python lidar/tools/build.py`。需要 Python 3.9+、GNU Arm GCC，雷达板另需 CMake 3.20+ 和 Ninja。环境变量 `CHASSIS_GCC`、`ARM_GCC`、`CMAKE`、`NINJA` 可指定对应可执行文件，输出分别位于 `build/nav1k/` 和 `lidar/build/Release/`。本次主控和雷达板均在发布工作树编译通过。`firmware/current/` 和 `lidar/firmware/current/` 是旧版发布包，版本以各自的 `build.json` 为准。

主控映像基址 `0x08000000`，保留 sector 7（`0x08060000–0x0807FFFF`）中的机械臂标定。驱动器重启后仍需要恢复实体参考。

## 正式流程与调试入口

- `mission start official` 从实际启停区出发，先到二维码位置，使用 UART5 OpenMV 获取任务码，冻结雷达障碍目录后规划工作路线。按任务码处理两批顺序及工位，第一批暂存平放，第二批在同色底块上码垛，最后返回本轮出发区。
- `mission start` 提供原固定顺序调试入口。先确认实体参考、等高工位、分段路线和收臂姿态。`mission status` 查看任务状态，`mission stop` 或 `!` 停止。
- 正式流程对仅有低质量视觉的工位可以沿用已教导位置。明确缺块、码垛缺底块或修正越界时跳过受影响的动作，继续其余可完成任务。`[MISSION_DONE]` 区分完整核验和部分完成。检测到通信、定位参考或机构故障时按停车联锁处理。
- 视觉姿态通过 `mission view TYPE PROFILE TURN_PWM CAMERA_PWM` 设置，类型支持 `qr`、`raw`、`rough`、`storage`、`tray`。先标定相机和升降姿态，再与 OpenMV 配置对应档位。正式视觉取料需要当前目标状态和档位有效，实际接入及误差还需装车确认。

## 新机械臂接入

当前机械结构按回转、横向伸缩、升降三自由度建模。`nav_arm2_profile.c` 集中放预览轴心、TCP、行程、速度和加速度。`arm2 solve X Y Z` 查询可达性，`arm2 plan X0 Y0 Z0 X1 Y1 Z1` 打印分段规划，坐标单位为毫米，车头为 +X、车左为 +Y、高度朝上。几何和轴速待新总装标定。

`arm2 version`、`arm2 position`、`arm2 flags` 在空闲时读取预定伸缩轴 ID6。升降预定沿用 ID5。双轴同步帧状态在 `nav_arm2_emm.c`，用于先有地址应答再同步触发的准备。实际电机型号、串口电气层、清除缓存、到位反馈和执行接入待台架核对。当前比赛入口使用标定过的旧机构，新轴尚处于读回与离线规划阶段。

供料盘以当前工位的有效停稳反馈作为下探依据。约 6 秒只用于估算，换位时间随原料盘实际运行变化。新转盘反馈尚未接入实际比赛入口。

新机构装车时须校核带料转向包络、回转中心到车中心的偏置、各轴零点与传动比、夹爪中心及三工位位置。握持物块的最低避让高度和两个取放平面的实测值直接影响节拍。参考 CAD 的齿条阵列标注与小齿轮理论齿距有差异，装机前应核实啮合尺寸。
