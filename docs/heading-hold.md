# 航向保持实验与已知问题

当前v2.1.5。代码已烧录使用且有原板读回记录；长纠偏尚未调通，不能作为完成的行走控制使用。普通`left_16000`仍为无整车航向纠偏的基线。

## 结构

`heading_hold.c`保留独立授权，`arm hold`与`arm all`互不替代。捕获起点Yaw，按最短角差计算P补偿：8脉冲/度，死区±0.15°，限幅±16脉冲；无积分，未使用角速度微分。正Yaw误差对应逆时针偏，叠加顺时针修正。

左移每段基础160脉冲：前轮幅值160−补偿，后轮160＋补偿，方向组合不变，单轮范围144～176。短档1600总预算、8秒上限；长档16000、80秒上限；100段的节奏与原连续位置基线不同，不能当作严格同工况对照。

每段需四个位置确认，随后连续两轮四台均报告使能、到位且无堵转，才进入下一段。诊断档只发一段、不施加纠偏，追加读取0x37误差、0x35转速、0x33最终目标、0x34轨迹设定位置，不改变原衔接门槛。

保护包括：IMU角度/角速度过期300ms、新增校验/串口错误、偏角超过8°、主机心跳丢失1500ms、回复超时300ms、单段2500ms、总期限、命令拒绝、stop或意外命令。停止逐台发送到地址1～4，禁止广播或升降地址5。软件期限依赖MCU运行，不覆盖所有电气故障。

| 记录 | 结果 |
|---|---|

| H01 / v2.1 | 初版错误解释高位0x80，启动前退出；未运动，后已修正仅使用已知故障位 |
| H02 / v2.1.1 | 第一段160脉冲后3/4号未到位，2.5秒保护停止，未走长行程 |
| D01 / v2.1.3 | 四轮均转、停稳；1/2/3到位，4号残差64计数约0.35°、未到位 |
| P01 / v2.1.4 | 四台两轮参数均有效：到位窗口0.3°、位置PID相同；未写配置 |
| D02 / v2.1.5 | 四轮均转、停稳；四台后期RPM0，轨迹设定值等于最终目标，但残差0.32°～0.61°均超过0.3°，超时停止 |

D02把问题从“4号单轮”扩展为小段结束时的残余位置跟踪误差。轨迹设定值走到终点不代表机械轴误差为零；转速读数为0也不是无微动的独立仪器证明。没有据此判定硬件损坏或跳过保护。

后续应先分析有限分段衔接的可行判据及累计目标误差，再以单次短行程验证；PID、电流、到位窗口和软件进段规则均尚未调整。即使航向稳定，向前/后平移偏差和横移距离仍需单独标定。
