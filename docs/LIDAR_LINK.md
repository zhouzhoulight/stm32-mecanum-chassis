# 主控与LD19板的链路及坐标约定

> 2026-11-14更新：当前候选主控v2.7.38、雷达0.3.5_FRONT150；有效视场原始195°..345°，后窗已停用，下文后窗仅为历史协议说明。自动二维码冻结只接入纯导航，二维码板专用关联尚未实现。见[最新详细交接](HANDOFF_V2738_20261114.md)。

## 硬件和职责

主控USART2 PA2(TX)/PA3(RX)，雷达板USART3 PB10(TX)/PB11(RX)，交叉接线、共地、230400 8N1，3.3V TTL。雷达板PA3连接LD19，是另一块板上的另一路串口，不能与主控PA3混淆。

主控拥有地图、车身几何、实时制动和九路口路径规划。雷达板完成采集、分圈、滤波、特征跟踪及接收运动提示，不能接收PC规划好的路线替代下位机规划。电脑调试口与板间口分开。

## 帧封装

```text
AA 55 CMD SEQ LEN PAYLOAD[LEN] XOR
```

LEN为1字节、最大250；XOR为此前所有字节异或，使整帧异或为0。多字节整数小端，浮点为32位IEEE754；时间戳用无符号回绕差处理。不能将毫秒和微秒混用。

| 命令 | 方向 | 载荷 |
| --- | --- | --- |
| 0x66 | 主控→雷达 | 4字节，主控发送时刻ms，原样作为请求标识 |
| 0xE6 | 雷达→主控 | 12字节：请求标识、雷达处理接收时刻us、发送前时刻us，各u32 |
| 0x68 | 主控→雷达 | 5字节：会话u32＋启用u8(0/1)，重置/启用当前运动上下文 |
| 0xE8 | 雷达→主控 | 原样5字节确认；主控只接受当前会话且启用为1 |
| 0x65 | 主控→雷达 | 20字节：雷达时钟us/u32、激光坐标系位置x/y浮点mm、yaw浮点rad、位置sigma/u16 mm、角度sigma/u16 mrad |
| 0x73 | 雷达→主控 | 扫描分批轨迹，11字节批头＋每项32字节，单批最多7项 |
| 0x75 | 雷达→主控 | 8或12字节视野元信息：主视野起止u16(0.01°)、扫描时刻us/u32，12字节版再含后窗起止u16 |

0x73批头为扫描时刻us/u32、scan_id/u32、batch/u8、total/u8、count/u8。记录字段按`features_tracks_payload()`和主控`frame()`成对维护。两侧须拒绝长度错误、乱序/缺批、过旧扫描、非有限坐标和超容量数据，不能把一半扫描当完整地图。

完整电脑侧INFO/RAW/FEATURE/STATUS协议实现保留在雷达板`protocol.h/.c`，本次文档重点为整车链路。帧形状延续原AA55风格，但不是把原OpenMV视觉载荷直接套用。

## 坐标

车体+X向前、+Y向左；雷达原始270°向前、180°向右，安装前移120mm。主控通过`lidar mirror on`、`lidar mount 120 0 90000`完成手性与外参转换。反射坐标系不能只用单个SE(2)yaw表达，运动提示的全局镜像也必须一致。修改外参、模式、会话时清理旧锚点/记忆，禁止继续沿用旧坐标数据。

主控保留历史姿态，按扫描时刻插值后投影至导航N坐标。雷达去畸变使用主控提供的激光位姿，不提供独立世界真值。fused与雷达landmark修正是不同层，不能把同源运动提示重复算成独立传感器证据。

## 同步、新鲜度和故障

- 运行同步年龄≤3000ms、扫描年龄≤500ms；启动要求更近的同步和扫描及起始之后的几何数据。
- 时钟回包往返>20ms不接受；处理耗时不得大于可用往返时间；偏移突变>20ms重建会话。
- v2.7.31增加重试并修复入队失败的请求标识，不放宽质量或过期保护。
- 长路径搜索冻结几何输入，但系统仍处理链路；停止恢复前检查新路径和最新障碍。
- 视野外是未观察，不是自由区域；暂时遮挡不等于障碍已消失。后方4°窗口不能保证倒车全覆盖。
- 近处危险回波即使世界投影在场外也保留车体制动证据；完整处于场外且无近障证据的对象才可筛去。场外观众侵入场内不能被全部忽略。

## 故障现场

先保存status/odom和lidar status、hazard、hazard live/near/memory、plan live/memory。LIDAR_CLOCK有RTT/处理耗时/入队失败/旧包等计数。HAZARD是触发瞬间数据，PLAN是搜索时快照，不要停车后随意重置再问当时为什么停。

RAM地图最多48个圆，不是W25Q128永久地图；满容量、失效或不同步必须有明确处理，不能静默用未知数据继续运动。当前已知问题详见总交接。
