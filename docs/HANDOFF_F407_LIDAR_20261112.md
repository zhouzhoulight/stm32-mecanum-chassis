## 2. 目标与实测背景

场地2400×2400mm，整车约300×300mm，四个黄色禁行区只是地面色块，雷达不能直接凭高度识别。随机黑柱约φ50×100mm。原料盘、二维码板开赛时位置有范围变化，比赛中保持不动；不能预先当作精确已知地标。

完整任务：每批原料取三块→粗加工按1、2、3放置→仍按1、2、3取回→左侧暂存区第一批平放、第二批码垛→直接回启停区1。**不得把取回改成3、2、1。** 当前没有抓到物料/接触传感器，完成日志只表示指令执行，不能自称每块真实成功。

此前已实测长距离平顺运行、转向叠加以及grab/rough/unrough/stack。base与fused未稳定证明谁明显更准；完整取放曾出现厘米级累计误差及码垛偏位。目标整套约150秒，**目前未验证达成**；旧速度候选的理想时间不能当作当前比赛成绩。

## 4. v2.7.31的主要修改

1. 路径搜索使用冻结的实时障碍和记忆地图快照，防止一次长搜索中世界悄悄变化；实时制动仍持续读取新数据，恢复前重新核对路径。失败规划输入保留。
2. 时钟刷新加入更密集重试，发送入队失败不替换最近有效请求标识。20ms往返质量门限、20ms时钟跳变检查、运行3s失效及启动新鲜度要求没有放宽。
3. 增加同步计数和触发瞬间HAZARD快照，区别真正触发时的数据与停车后的扫描。
4. 修复扫描时刻姿态插值；fused修正同步移动关联近障几何和诊断扫描姿态。
5. 场外ROI只丢弃整个包围圆都在场外的对象；中心在场外但侵入场内的对象保留。
6. 车体坐标的近处危险证据不因世界坐标漂移到场外而消失。视野边缘对象继续参与实时制动，但不直接固化为永久地图。

没有扩大自身屏蔽、缩小车体或放宽超时来制造“通过”。自身屏蔽仍为当前设置声明的145mm矩形，不能擅自扩大覆盖真实近障。

## 5. 离线验证摘要与边界

- 主控离线套件67项构建/执行检查通过，不是67次实车。
- 雷达实际C原生检查225个断言通过。
- MATLAB/实际C联合场景为27个当前候选＋3个旧版对照。30个结果中20个完成且通过独立几何审计、5个预期停车；**4个当前版本反例仍失败**，另有1个旧版同步失败被复现，并非全通过。
- 每版本804次正常/可恢复时序压力试验（800次短试验＋4次30分钟模拟时间）：当前同步过期0次、旧版201次；最大模拟同步年龄约2099ms对8398ms。持续45ms往返延迟或5s链路中断仍应过期停车。
- 模型包含独立地面真值、轮地约束、230400串口FIFO、扫描延迟与部分视野；不代表所有供电、遮挡、反射和驱动器实物行为。
- 无障碍模型导航约94.6秒、双柱示例约111.8秒，**不含完整机械臂流程和MCU规划墙钟耗时，不是比赛完成时间**。板上规划可能耗时数秒，需计入实际总时长。

原始实验数据与仿真脚本不随此次上传，以上仅交接摘要；公开仓库可重新构建生产固件，不能单靠它重放全部既有仿真。

## 6. 已知未解决问题

| 问题 | 影响与方向 |
| --- | --- |
| 约148mm自身边缘回波刚好在145mm屏蔽外 | 可能误停；需实车结构遮挡标定与关联证据，不能删光近回波 |

| 严重打滑 | IMU＋驱动轮编码器无法观测全部平移误差；仍有模拟越黄区反例，不能承诺3mm全图误差 |
| 300mm蓝区与300mm车身同宽 | 起点小偏航/位移就可能拒绝规划；不能途中反复重建原点掩盖误差 |
| 后视仅原始约88°～92° | 非完整后方可见；记忆不能保证后方没有新障碍 |
| 升降驱动器断电/清零 | Flash高度仍在，但驱动器计数参考可能已变，须恢复已知实体姿态 |
| MPC整圈 | 当前route start明确禁止MPC整圈，仅受控单段试验，不移除门控冒充已验证 |

## 7. 下次实车顺序

1. 核对两板、总线供电及机械臂真实姿态，先备份sector7，再选定镜像。
2. 只读检查版本、五驱动器反馈、IMU、雷达同步/扫描年龄/外参/可见方向。静态分别测试近障、场外观众与侵入物。
3. 不猜测升降位置，恢复已知实体零点或避让高度，确认机械臂收拢后再动底盘。
4. 用户明确同意后，先短程再同一路线完整导航。完整留日志，正常运行无需持续人工查看，异常停车后读取HAZARD/PLAN。
5. 整圈通过后再取放及变换障碍。记录真实起止/重复工位偏差及总时长，不用估计轨迹自证准确。
6. 提速先审计路径、转向加速度、载荷及可叠加动作，再验证实车；不能以移除保护代替修复。
