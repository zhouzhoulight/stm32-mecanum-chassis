# 基线与诊断命令

上电只停止/失能，等待串口命令。一次授权只执行一次动作，10秒内未使用即过期。以下基础入口在v2.1.5中保留，主机/设备回复不代替现场观察。

| 命令 | 行为 |
|---|---|
| `help` / `status` | 帮助、芯片、引脚、固件与运行信息 |
| `stop` | 对1～4号发停止和失能，撤销授权 |
| `probe 1`至`probe 4` | 查询指定驱动器版本，不使能或运动 |
| `imu` | IMU角度、角速度、新鲜度及错误计数 |
| `imu baud N` | 仅改MCU接收波特率，不写传感器；本车115200 |
| `arm N`，再`jog 0`或`jog 1` | 单轮点动，5RPM、160脉冲、3秒停止上限 |
| `arm all`，再`forward/back/left/right/cw/ccw`之一 | 四轮单次动作，5RPM、160脉冲、3秒上限 |
| 六种方向后加`_long` | 1600脉冲、8秒上限；仍需`arm all` |
| `forward_16000/left_16000/right_16000` | 16000脉冲、80秒上限；仍需授权和足够空地 |
| `forward_1m/back_1m` | 固定12924脉冲，名称源于F103历史标定；不保证F407走1米 |

所有运动都固定5RPM；`_long`和标定档只改变脉冲预算与停止期限。串口错误或发送失败触发停止/撤销授权，退出控制台尝试发送stop。不要把80秒保护期限当成已测实际走完时间。

先查四地址通信，再准备现场空地；每次动作后检查真实方向、距离与停稳，再决定是否进行下一次。

## v2.1.5只读与实验入口

| 命令 | 行为 |
|---|---|
| `driver_config 1`至`driver_config 4` | 读取配置，含到位窗口；不写参数，不使能或运动 |
| `driver_pid 1`至`driver_pid 4` | 读取位置环PID原始整数，不写参数 |
| `hold_diag 1`至`hold_diag 4` | 静止时读取位置误差，不证明上次已到位 |
| `hold_status` | 实验状态；启动前未捕获参考的delta不作相对偏航 |
| `arm hold`后`left_diag_160` | 只发一段160脉冲，5RPM、不纠偏；运动中读状态、误差、RPM、最终目标及轨迹设定值 |
| `arm hold`后`left_hold_1600`或`left_hold_16000` | 未调通的分段左移航向保持实验；非默认工作模式 |
| `hold_keep` | 实验期间主机每500ms以内发一次心跳，超过1500ms停止 |

手工控制台不自动发送心跳；不要手工启动长hold实验后只等待。离线测试通过不代表本车纠偏成功。当前到位门槛仍会使小段衔接中止，未提供自动重试脚本或默认长行程启动入口。

## WT901新增校准诊断

本地增量 `v2.1.6-imu2`：`imu zero`、`imu drift`、`imu tx on/off`、`imu read mode/output/filter/version`、`imu cal acc`、`imu cal stop`、`imu cal check`、`imu save`、`imu cancel`。详见 [WT901接线与操作](wt901-calibration.md)。默认TX关闭，不自动校准或保存；运动参数沿用v2.1.5。
