# F407 接线与硬件

当前平台：STM32F407VET6，25MHz主晶振，软件时钟168MHz，512KiB Flash / 128KiB连续SRAM；未使用64KiB CCM。HCLK是软件配置值，非仪器测量。三个串口均为115200、8N1。

| 功能 | F407引脚 | 对端 |
|---|---|---|
| 控制台 TX | PA9 / A9 | 无线车端 RXD |
| 控制台 RX | PA10 / A10 | 无线车端 TXD |
| 电机 UART4 TX | PA0 / A0 | 驱动器实际 RX |
| 电机 UART4 RX | PA1 / A1 | 驱动器实际 TX |
| IMU USART3 RX | PD9 / D9 | WT901CTTL TX |
| IMU发送预留 | PD8 / D8 | 当前保持高阻；WT901 RX可留空 |
| SWD数据 | PA13 / SWDIO | CMSIS-DAP DIO |
| SWD时钟 | PA14 / SWCLK | CMSIS-DAP CLK |
| 可选复位 | NRST | 下载器RST；主控按键RESET也可复位 |
| 公共地 | GND | 下载器、驱动器、传感器及电源地 |

BOOT0保持0。F103旧接法A2/A3、早期F407的PC10/PC11均不适用于当前固件。分配板TX/RX丝印方向未经原理图核实，应以驱动器本体RX/TX功能核对。

WT901CTTL标签面朝上固定于车身。VCC使用该模块版本支持的、已确认稳压电源；当前推荐接经核实的5V，GND共地，TX接PD9，RX可不接。本轮未测量实际供电；不要将电源5V/6V/12V接到主控3V3。不同模块版本的最低供电不能凭外壳推定。

主控供电按具体开发板说明连接。电机大电流走电池与分配板的原动力线，不经主控或下载器细线回流。不并接未确认方向的电源输出。改线先断相关电源。

## 四轮与驱动器

从上方看麦轮滚轮为X布局。地址：左前FL=4、右前FR=1、左后RL=3、右后RR=2；各轮前进方向位均为1。程序只向地址1～4发命令，不使用广播0或升降电机5。

FL/FR/RL/RR方向组合：前进`++++`、后退`----`、左移`-++-`、右移`+--+`、顺时针`+-+-`、逆时针`-+-+`。`+`代表经现场核对的前进方向；接线或电机安装变动后须重新验证。

驱动器：Emm V5，UART_FUN，115200，固定校验0x6B。具体实读参数及版本边界见实测文档；不能据旧控制器标定直接宣称新主控距离精度。
