# 实测与发布验证

归档日期2026-10-28，最近一次现场记录2026-10-27。本仓库同时保存v2.0基线和v2.1.5诊断程序。此次发布仅整理文件、离线测试和GitHub上传，未访问主板或转动电机。

已记录的F407现场结果：

- 前进`forward_long`：5RPM、1600脉冲、8秒停止上限，用户确认正常前进并停稳，距离未量；41条有效航向记录，最终变化+0.115°。
- 左横移L01：5RPM、16000脉冲、80秒上限；119.5cm左移、3.5cm后偏、人工估计水平偏4°、已停稳；401条有效航向记录最终变化+5.455°。没有启用纠偏。
- 两次均保留动作/停止/失能回复与用户现场反馈；回复证明通信，现场反馈证明动作及停稳。

尚未证明：F407精确1米、全部方向重复精度、横移距离闭环、航向保持效果、故障条件下的全部电气保护。F103历史一米试走不作为F407精度证据。原生电机闭环与整车航向保持是不同控制层。

离线验证使用`scripts/check.py --firmware`。这不是实车测试，不会访问串口、SWD或转动电机。归档固件的原板读回证据与发布目录重新构建证据分别标识。

## v2.1.4参数查询与v2.1.5诊断

P01两轮读取：四台到位窗口均0.3°，位置环原始PID均Kp=26000、Ki=10、Kd=26000。只读，不是新调出的参数。4号CAN速率编码与其他不同，但本车使用UART，不据此认定横移故障原因；左右侧Dir配置不同，沿用实车核对过的方向，不擅自统一。

D02只执行一段160脉冲，4台均回复位置指令及定时停止/失能。四台最后均未报告到位，无堵转位；最终目标与轨迹设定值分别相同，后期RPM读数为0，仍有电机轴误差：右前1号−0.489°、右后2号+0.324°、左后3号+0.374°、左前4号−0.610°。查询顺序串行，非严格同一时刻采样。

15条YAW全有效，最终变化−0.016°；本轮无纠偏、行程很短，不能据此认定纠偏有效。用户明确反馈“已停稳，四个轮子都转了一小段”。运动完成时间、距离未独立测量。

最新结论：分段衔接受真实的小幅定位误差与0.3°到位窗口限制，问题不是仅4号或整条总线失联。残差根因仍未锁定；没有改PID、电流、到位窗口、软件到位门槛或自动重试。下一步须设计有轨迹/速度/误差约束的衔接策略并短程验证，不能直接宣称长纠偏可用。
