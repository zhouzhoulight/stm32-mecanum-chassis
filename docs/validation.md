# F407 v2.0 基线的验证边界

本标签保存添加分段航向保持实验前的源码及现场BIN。归档不自动接触硬件，不代替每次上电检查。

已记录的F407现场结果：

- 前进`forward_long`：5RPM、1600脉冲、8秒停止上限，用户确认正常前进并停稳，距离未量；41条有效航向记录，最终变化+0.115°。
- 左横移L01：5RPM、16000脉冲、80秒上限；119.5cm左移、3.5cm后偏、人工估计水平偏4°、已停稳；401条有效航向记录最终变化+5.455°。没有启用纠偏。
- 两次均保留动作/停止/失能回复与用户现场反馈；回复证明通信，现场反馈证明动作及停稳。

尚未证明：F407精确1米、全部方向重复精度、横移距离闭环、航向保持效果、故障条件下的全部电气保护。F103历史一米试走不作为F407精度证据。原生电机闭环与整车航向保持是不同控制层。

离线验证使用`scripts/check.py --firmware`。这不是实车测试，不会访问串口、SWD或转动电机。归档固件的原板读回证据与发布目录重新构建证据分别标识。
