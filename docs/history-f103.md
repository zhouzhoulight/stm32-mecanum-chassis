# F103历史测量（不适用于直接证明F407精度）

2026-10-22，STM32F103C8T6阶段，同一套四麦轮和Emm V5，5RPM。当前公开固件目标是F407，不能烧到F103。

| 项目 | 指令 | 用户实测 |
|---|---:|---:|
| 前进F01 | 16000脉冲 | 123.6cm |
| 前进F02 | 16000脉冲 | 124.0cm |
| 前进F03 | 16000脉冲 | 123.8cm |
| 目标1m前进V01 | 12924脉冲 | 99.9cm |
| 目标1m后退B01 | 12924脉冲 | 99.9cm（用户确认单位为cm） |

前三次均值123.8cm、极差0.4cm，形成129.24脉冲/cm的算术初值。前后各一次接近1m，不等于独立证明毫米级精度、返回残差或长期重复性；实际走完时刻未独立验证。

左移16000脉冲的五次历史距离：117.7、125.7、120.7、120.6、120.5cm。最近三次较接近，但保留全部五次，不删除早期差异。L05有400条有效航向记录，IMU变化+3.823°，用户估计向左约4°，未启用纠偏；前约50秒偏角逐步增加，之后平稳，但不能仅凭曲线推断实际停住时刻。

F407重新测得的基线是119.5cm、后偏3.5cm、IMU变化+5.455°，应单独使用。尚未采用横移脉冲/厘米系数，也未实现横移1米命令。

选取的F103测距JSON与L05 CSV保存在`records/history-f103/`，原F103源码及其他档案仍保留于原本地工程，本仓库不混入F103固件目标。
