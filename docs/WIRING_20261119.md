# 工创整车接线表

2026-11-19 · 主控 `v2.7.43-arm2-preview-20261118` · LD19 处理板 `0.3.5_FRONT150`。两块板都使用 STM32F407VET6，外部晶振 25 MHz，系统时钟 168 MHz。表中 TX、RX 从各自设备看，串口均为 8N1。

## 主控与外设

| 功能 | 主控发送线 | 主控接收线 | 波特率与备注 |
| --- | --- | --- | --- |
| 电脑调试 / DAPLink 虚拟串口 | PA9 TX → 适配器 RXD | PA10 RX ← 适配器 TXD | USART1，115200。此前主控枚举为 COM13 |
| Emm 电机总线 | PA0 TX → 驱动器总线 RX | PA1 RX ← 驱动器总线 TX | UART4，115200，地址见下表 |
| 雷达板 | PA2 TX → 雷达板 **PB11 RX** | PA3 RX ← 雷达板 **PB10 TX** | 主控 USART2 ↔ 雷达板 USART3，230400 |
| WT901CTTL IMU | PD8 TX → WT901 RX | PD9 RX ← WT901 TX | USART3，默认 115200。PD8 上电为高阻，需发 IMU 指令时使用 `imu tx on` |
| OpenMV | PC12 TX → OpenMV RX | PD2 RX ← OpenMV TX | UART5，115200。OpenMV 端引脚按其实际型号和程序选用的 UART 确认 |

每条通信链路另接双方 GND。主控与雷达板之间只需要两条信号线及一条地线，串口为 3.3V TTL。主控 PA3 接雷达板 PB10，LD19 的 TX 接的是**雷达板** PA3。

## SWD 下载与停稳反馈

主控和雷达板分别接各自的 DAPLink。`SWDIO → PA13`、`SWCLK → PA14`、`GND → GND`，下载器复位脚可接 `NRST`。带 `VTref` 的探针按其说明连接目标板参考电压。下载前按板子和探针核对目标，COM 号会随 Windows 枚举变化。

场地原料转盘的停稳反馈仍待接入。后续由转盘控制器或视觉确认当前取料工位已到位并停稳，再允许新机构下探，接入方案确定后再分配通信接口。约 6 秒是仿真估计。
